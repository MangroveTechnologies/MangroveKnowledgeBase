# System Overview

This page describes how the public-facing pieces of the Mangrove ecosystem compose. It is **not** a deep architecture document — it's a map of what calls what, so you can pick the right entry point.

## Service responsibilities

| Service | Production URL | Owns |
|---|---|---|
| **MangroveAI** | `api.mangrovedeveloper.ai/api/v1` | Strategies, backtesting, AI copilot, execution, crypto assets, market data, accounts |
| **MangroveKnowledgeBase** | `kb.mangrovedeveloper.ai` | Signal/indicator metadata, signal evaluation, indicator computation, KB search/glossary |
| **MangroveMarkets** | `api.mangrovemarkets.com` | DEX aggregation, agent marketplace, wallet ops, CEX data |
| **MangroveTrader** | `api.mangrovetraders.com` | Social trading leaderboard, Twitter agent, x402 micropayments |

Each service exposes both **REST** and **MCP** (Streamable HTTP) on the same domain. Choose REST for backend integrations, MCP for agent integrations.

## How signals and indicators flow

The `mangrove-kb` Python package is the single source of truth for signals and indicators. It is:

1. **Imported directly** by anyone who installs `pip install mangrove-kb` and runs computation locally.
2. **Imported by the MangroveKnowledgeBase server** which exposes `/api/evaluate` (signal) and `/api/compute` (indicator) over REST and MCP, both x402-gated.
3. **Imported by the MangroveAI platform** which wraps signal evaluation in higher-level constructs (strategies, backtests, AI copilot recommendations).

Update the signal docstring in `mangrove-kb` and metadata propagates everywhere — REST `/signals/{name}`, MCP `kb_list_signals`, the MangroveAI strategy validator, and this documentation site (via `scripts/generate-signal-catalog.py`).

## Authentication models

| Surface | Auth |
|---|---|
| MangroveAI REST/SDKs | Firebase OAuth → JWT, or API key |
| MangroveKnowledgeBase free endpoints | None (public) |
| MangroveKnowledgeBase x402 endpoints (`/evaluate`, `/compute`) | x402 micropayment in USDC on Base, or API key |
| MangroveMarkets MCP | API key, or x402 for premium tools |
| MangroveTrader x402 tools | x402 in USDC on Base |

x402 is a payment protocol that lets agents pay-per-call without subscription. Send a request without payment → server returns `402 Payment Required` with price and network details → sign payment → resend with payment header. The SDKs and Claude Code plugins handle this round-trip for you.
