# RAG System

MangroveAI implements a Retrieval-Augmented Generation (RAG) system to enhance the AI Copilot's responses with domain-specific trading knowledge. The system uses PostgreSQL with the pgvector extension for vector similarity search.

## Architecture

```
AI Copilot
    |
    | Query
    v
RAG Service
    |
    +-- Query Embedding --> OpenAI Embeddings API
    |
    +-- Vector Search ----> PostgreSQL + pgvector
    |
    +-- Document Retrieval -> Ranked Results
    |
    v
Context Injection into LLM prompt
```

## Components

### Vector Database

The vector database stores document embeddings in PostgreSQL with pgvector:

```sql
CREATE TABLE knowledge_embeddings (
    id SERIAL PRIMARY KEY,
    document_id VARCHAR(255) NOT NULL,
    chunk_text TEXT NOT NULL,
    embedding vector(1536) NOT NULL,
    metadata JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

- Uses OpenAI `text-embedding-ada-002` for 1536-dimensional embeddings
- Chunks are created from the 11 knowledge base documents plus signal documentation
- Cosine similarity search for semantic matching

### Document Chunking

Documents are split into chunks based on:
- Section headers (H2, H3 boundaries)
- Maximum chunk size (configurable)
- Overlap between chunks for context continuity

### Query Pipeline

1. User message is converted to an embedding vector
2. Cosine similarity search finds the top-k matching chunks
3. Matching chunks are ranked by relevance score
4. Top chunks are injected into the LLM prompt as context
5. The LLM generates a response informed by the retrieved knowledge

## Initialization

The RAG vector database is seeded on first startup:

1. All knowledge base markdown files are loaded
2. Each document is chunked by section
3. Chunks are embedded via OpenAI API
4. Embeddings are stored in PostgreSQL

### Refreshing the Database

Admins can refresh the vector database when documentation changes:

```bash
curl -X POST "http://localhost:5001/api/v1/ai-copilot/admin/refresh-vector-db" \
  -H "Authorization: Bearer $TOKEN" \
  -H "X-Management-Key: YOUR_MGMT_KEY"
```

This clears existing embeddings and re-seeds from current documentation.

## Performance

- Embedding generation: ~0.1s per chunk via OpenAI API
- Vector search: &lt;50ms for cosine similarity over 1000+ chunks
- Context injection adds 500-2000 tokens to each LLM request
- Total RAG overhead per query: ~200ms
