# Welcome to Mangrove

Mangrove is a trading strategy development and backtesting platform. It provides a complete toolkit for building, testing, and deploying algorithmic trading strategies -- from signal discovery through backtesting to live execution.

## What Mangrove Provides

<CardGroup cols={2}>
  <Card title="223 Trading Signals" icon="chart-line">
    Pre-built technical indicators across momentum, trend, volume, volatility, and patterns categories. Each signal is classified as TRIGGER (event-based) or FILTER (state-based) for precise strategy composition.
  </Card>
  <Card title="AI Copilot" icon="robot">
    Conversational AI that guides you through strategy creation. Describe your trading idea in natural language and the copilot maps it to signals, assembles a strategy, and runs a backtest.
  </Card>
  <Card title="Backtesting Engine" icon="clock-rotate-left">
    Test strategies against historical market data with comprehensive performance metrics including Sharpe ratio, max drawdown, win rate, and trade-by-trade analysis.
  </Card>
  <Card title="Execution Engine" icon="bolt">
    Stateful strategy execution with position management, stop-loss/take-profit orders, and risk controls. Supports both dry-run evaluation and persistent state tracking.
  </Card>
</CardGroup>

## Platform Architecture

MangroveAI is built as a Flask REST API with 60+ endpoints across 16 domains:

- **Signals** -- 223 trading signals (108 TRIGGER, 115 FILTER) built on a library of 99 technical indicators
- **Strategies** -- CRUD operations with signal composition rules (1 TRIGGER + 1 FILTER per entry)
- **Backtesting** -- Historical strategy testing with market data integration
- **Execution** -- Real-time strategy evaluation with position and order management
- **AI Copilot** -- Conversational workflow for guided strategy creation
- **Crypto Assets** -- Asset data, risk scoring, and on-chain analytics
- **Market Data** -- OHLCV, trades, and quotes from multiple providers

## Who This Is For

**Developers** building integrations with the MangroveAI REST API. You need authentication guides, endpoint references, and code examples.

**AI Agents** consuming MangroveAI endpoints programmatically. You need structured, machine-readable API documentation with clear parameter schemas.

**Traders and Researchers** exploring signals and indicators. The Knowledge Base covers market foundations, strategy design, risk management, and a comprehensive indicator reference. You can also use the open-source `mangrove-kb` Python package to compute signals and indicators locally without going through the API.
