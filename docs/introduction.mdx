# Welcome to Mangrove

Mangrove is a developer ecosystem for building **agent-native** trading, marketplace, and DEX-aggregation applications. Whether you are calling REST APIs, dropping in a Python SDK, or integrating an MCP server, Mangrove gives you the primitives.

The core building blocks are open: 233 trading signals and 99 technical indicators are MIT-licensed in the `mangrove-kb` Python package. The full platform — strategy management, backtesting, AI copilot, DEX aggregation, social trading — is exposed as a unified developer surface across REST, MCP, and SDKs.

## Pick your integration path

| If you are... | Start with |
|---|---|
| Calling REST endpoints from any language | [API Reference](/api-reference/overview) |
| Writing Python for the platform | [`mangroveai` SDK](/sdks/mangroveai) or [`mangrove-kb`](/sdks/mangrove-kb) for local signals |
| Writing Python for DEX / wallet / portfolio | [`mangrovemarkets` Python SDK](/sdks/mangrovemarkets) |
| Writing TypeScript / Node | [`@mangrove-ai/sdk`](/sdks/mangrove-markets) (DEX + marketplace) |
| Building an agent (Claude, custom MCP client) | [MCP Servers](/mcp-servers/mangrove-markets) |
| Standing up a turnkey trading bot | [Mangrove Agent](/mangrove-agent/overview) — clone, set API key, deploy |
| Researching strategies or learning markets | [Knowledge Base](/knowledge-base/market-foundations) |

## What's free vs. paid

- **Free, no auth:** signal/indicator metadata, knowledge-base search, public market education, MCP tool discovery, leaderboard previews.
- **Free, requires account:** strategy CRUD, backtesting (limits apply), AI copilot conversations, signal evaluation up to your tier limit.
- **x402 micropayments:** premium leaderboard data, signal evaluation beyond tier limit, indicator computation, trader history. Pay-per-call in USDC on Base. No subscription required for x402 endpoints.

## Source code

Mangrove is built by [Mangrove Technologies](https://github.com/MangroveTechnologies). The signal library, knowledge base, agent template, and this documentation site are open source:

- [`MangroveKnowledgeBase`](https://github.com/MangroveTechnologies/MangroveKnowledgeBase) — `mangrove-kb` Python package, KB server, public docs source
- [`mangrove-agent`](https://github.com/MangroveTechnologies/mangrove-agent) — FastAPI + MCP trading-bot template (MIT)

The MangroveAI platform itself is closed-source; you consume it via the [`mangroveai`](/sdks/mangroveai) PyPI package or the [REST API](/api-reference/overview).
