# Signals Quick Reference

Alphabetical index of all trading signals available in MangroveAI. For detailed documentation, see the [Indicators](/knowledge-base/indicators) page or query the [Signals API](/api-reference/signals).

## How to Use This Reference

Each signal is listed with:
- Signal name (used in API calls)
- Type: TRIGGER (event-based) or FILTER (state-based)
- Category: momentum, trend, volume, volatility, or patterns
- Brief description
