# `mangrove-agent` — turnkey AI trading bot

`mangrove-agent` is a production-ready trading-bot template you clone and run. It turns natural-language goals ("momentum on ETH") into backtested, ranked trading strategies via the MangroveAI API; runs them on APScheduler cron jobs; and executes live swaps through MangroveMarkets with client-side signing.

It is **MIT-licensed**, lives in its own GitHub repo, and pairs with the [`mangroveai`](/sdks/mangroveai) and `mangrovemarkets` SDKs you already know.

## What you get

- Single FastAPI process on port 9080 — REST API + MCP server, same service layer.
- 41 MCP tools spanning wallet ops, DEX swaps, market data, signals, strategy creation, backtesting, execution, logs, knowledge base, and DeFi.
- APScheduler in-process cron with SQLite jobstore — same evaluator path for paper and live.
- Local Fernet-encrypted wallets. Bare-metal install puts the master key in your OS keychain; Docker install puts it in `./agent-data/master.key` (chmod 600, gitignored).
- Hooks that block key pastes in Claude Code so private keys never enter the chat.

## Quick start (bare-metal)

```bash
git clone https://github.com/MangroveTechnologies/mangrove-agent.git
cd mangrove-agent
./scripts/setup.sh
```

The setup script prompts for your MangroveAI API key (free at the [Developer Portal](https://app.mangrovedeveloper.ai)), creates a Python virtualenv, pip-installs dependencies, starts uvicorn in the background, registers the MCP server with Claude Code, and verifies `/health`.

When it finishes:

- Agent listens at `http://localhost:9080`.
- pid in `agent-data/bare.pid`, logs in `agent-data/bare.log`.
- Claude Code's MCP registration knows about `mangrove-agent`.

## Quick start (Docker)

If you can't run Python on the host:

```bash
git clone https://github.com/MangroveTechnologies/mangrove-agent.git
cd mangrove-agent
./scripts/setup.sh --docker
```

State persists in the `./agent-data/` directory (bind-mounted into the container). The Docker path cannot reach your OS keychain, so the master key lives at `./agent-data/master.key`.

## First strategy, no wallet

Start Claude Code in the repo directory. The agent runs a short platform tour and offers to help you build a strategy. Then:

> "Build me a momentum strategy for ETH on 1h. Use a reference."

The agent searches curated reference strategies, picks a candidate, builds it, backtests it with a timeframe-appropriate lookback, and reports PASS / MARGINAL / FAIL against six thresholds.

> "Promote it to paper."

The strategy schedules on a cron at its timeframe. Evaluations fire, paper fills get logged. No funds at risk.

## Going live

Wallet setup and live trading are gated behind explicit user actions. The summary:

1. `create_wallet` or `import_wallet` — secret returns as a `vault_token`, not plaintext.
2. `./scripts/reveal-secret.sh <vault_token>` in your terminal — prints the secret once, off-agent. Save it to your password manager.
3. `./scripts/confirm-backup.sh <address>` — flips the backup-confirmed flag. `execute_swap` and `update_strategy_status -> live` refuse on wallets without this flag.
4. Fund the wallet with 1-5 USDC on Base.
5. Promote the strategy to live with `confirm=true` and `slippage_pct <= 0.0025`.

Live evaluations fire on the same cron. When a strategy decides to trade, the `mangrovemarkets` SDK routes the order through 1inch, the agent decrypts the wallet's secret in-process, signs the transaction, broadcasts it, and zeroes the secret. The MangroveMarkets SDK never sees the key.

A real mainnet swap verified April 2026: [`0x5c126e...c5565`](https://basescan.org/tx/0x5c126e6be26fc736bcb3f11a8f4c699aeee754f6c0bf7e5b7aa2df6a859c5565).

## How it works

```
Claude Code -MCP-+
Python / curl -REST-+
                  |
                  v
+-- mangrove-agent (FastAPI, port 9080) ----+
|   . auth middleware (X-API-Key)           |
|   . service layer (REST + MCP share it)   |
|   . APScheduler cron (SQLite jobstore)    |
|   . local Fernet-encrypted wallets        |
+-------------------------------------------+
              |                |
              v                v
        SQLite agent.db    OS Keychain (Fernet key)
              |
              v
        mangroveai SDK            mangrovemarkets SDK
        (strategies, backtest,    (DEX swap, portfolio,
         signals, market data,     wallet ops)
         KB, on-chain)
```

Strategy evaluation happens inside `mangroveai.execution.evaluate()`. The agent does **not** re-implement signal logic, risk gates, position sizing, or cooldowns. It orchestrates: fetch strategy, call SDK, dispatch returned `OrderIntent[]` to the executor, log.
