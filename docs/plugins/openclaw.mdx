# OpenClaw Plugins

[OpenClaw](https://openclaw.dev) is an agent runtime that supports MCP plugins with deeper hooks — agent lifecycle events, dashboard UI, plugin paths registered globally rather than per-project.

The same Mangrove capabilities exposed as Claude Code plugins are also packaged as OpenClaw plugins.

## Available plugins

| Plugin | Wraps | Source |
|---|---|---|
| **mangrove-markets** | [MangroveMarkets MCP](/mcp-servers/mangrove-markets) | `MangroveMarkets/packages/openclaw-plugin/` |
| **mangrove-trader** | [MangroveTrader MCP](/mcp-servers/mangrove-trader) | `mangrove-trader-plugins/openclaw-plugin/` |
| **executive-functions** | [openclaw-executive-functions](/mcp-servers/openclaw-executive-functions) | `openclaw-executive-functions/oc-plugin/` |

## Install

```bash
openclaw plugins install @mangrove-ai/openclaw-plugin
openclaw plugins install @mangrove-ai/trader-plugin
openclaw plugins install @mangrove-ai/executive-functions-plugin
```

Or, for local development, register the plugin path directly in `~/.openclaw/openclaw.json`:

```json
{
  "plugins": {
    "paths": [
      "/path/to/MangroveMarkets/packages/openclaw-plugin",
      "/path/to/mangrove-trader-plugins/openclaw-plugin",
      "/path/to/openclaw-executive-functions/oc-plugin"
    ]
  }
}
```

## What OpenClaw plugins add over Claude Code plugins

OpenClaw plugins can register:
- **Tool definitions** that surface in the runtime's tool registry, callable by any agent.
- **Agent hooks** — `onAgentCall`, `onTaskComplete`, etc. — for cross-cutting concerns like usage logging, x402 settlement, and audit.
- **Dashboard UI** — custom tabs in the OpenClaw dashboard for plugin-specific state.

## Example tool definitions (mangrove-markets)

The OpenClaw plugin manifest for MangroveMarkets registers these tool names in the runtime:

- `mangrove_dex_quote` — swap quote
- `mangrove_dex_swap` — execute swap (signs and broadcasts)
- `mangrove_dex_status` — transaction status
- `mangrove_marketplace_search` — search listings
- `mangrove_wallet_info` — chain metadata
- `mangrove_wallet_create` — generate wallet
- `mangrove_portfolio_value` — aggregate portfolio across addresses

These map 1:1 to the underlying [MCP server tools](/mcp-servers/mangrove-markets) — the OpenClaw layer adds runtime hooks and dashboard integration.

## Build your own

To wrap an x402-gated MCP server with an OpenClaw plugin, start from the [`x402-plugin-template`](/templates/x402-plugin-template). The template includes scaffolding for both Claude Code and OpenClaw plugins — share most of the code, register the runtime-specific manifest separately.
