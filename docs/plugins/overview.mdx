# Plugins

Plugins wrap Mangrove MCP servers in ergonomic slash commands for two agent runtimes.

| Runtime | Page |
|---|---|
| Claude Code (Anthropic CLI) | [Claude Code plugins](/plugins/claude-code) |
| OpenClaw | [OpenClaw plugins](/plugins/openclaw) |

The same MCP servers back both — `mangrove-markets`, `mangrove-trader`, `executive-functions`. Pick the runtime you use; the capabilities are equivalent.

## Build your own

To wrap a new x402-gated MCP server with a plugin for one or both runtimes, use the [`x402-plugin-template`](/templates/x402-plugin-template).
