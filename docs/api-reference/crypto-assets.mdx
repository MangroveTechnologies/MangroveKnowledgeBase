# Crypto Assets API

The Crypto Assets API provides access to curated crypto asset data, risk scores, exchange listings, and real-time market intelligence with 19 endpoints across four categories.

**Base URL:** `http://localhost:5001/api/v1/crypto-assets`

## Endpoint Categories

| Category | Count | Description |
|----------|-------|-------------|
| Database | 6 | Cached asset and exchange data (updated daily) |
| Market Intelligence | 4 | Real-time market data and trends |
| Nansen Analytics | 4 | On-chain flow intelligence and smart money tracking |
| Admin | 5 | Asset management and data updates |

## Database Endpoints

### Query Assets

`GET /crypto-assets/query`

Query approved assets with risk scores, optimized for frontend dropdowns.

```bash
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost:5001/api/v1/crypto-assets/query?approved_only=true&min_score=70&limit=50"
```

### List All Assets

`GET /crypto-assets/all`

```bash
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost:5001/api/v1/crypto-assets/all?approved=true&min_score=70&limit=100"
```

**Response:**

```json
{
  "success": true,
  "count": 250,
  "assets": [

      "symbol": "BTC",
      "name": "Bitcoin",
```

Market-wide accumulation/distribution patterns.

## Risk Scoring

Assets are scored across 6 factors (0-100, higher = lower risk):

| Factor | Weight | Description |
|--------|--------|-------------|
| Market Cap | 25% | $10B+ = 100, $1B-$10B = 80, ... |
| Liquidity | 25% | Volume and volume/market cap ratio |
| Exchange Quality | 20% | Tier of listing exchanges |
| Volatility | 10% | 30-day annualized volatility |
| Price Stability | 10% | Maximum drawdown in 30 days |
| Supply Distribution | 10% | Holder concentration |

**Formula:**

```
Overall = (market_cap * 0.25) + (liquidity * 0.25) + (exchange * 0.20) +
          (volatility * 0.10) + (price_stability * 0.10) + (supply_distribution * 0.10)
```
